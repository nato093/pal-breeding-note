マスターと画像の出典

ID、図鑑番号、亜種、日本語名、英名は tylercamp/palcalc の PalCalc.Model/db.json を参照しています。コードのライセンスは MIT、ゲーム由来のデータの権利は Pocketpair, Inc. に帰属します。

属性は MagitekZed/palworld-helper の data/pals_work_suitability.csv、画像は同リポジトリの icons/pals/ を参照しています。同リポジトリにはライセンスの明記がなく、画像の権利は Pocketpair, Inc. に帰属します。

出典の詳細と固定した取得元は、プロジェクトの data/SOURCES.md と scripts/sources.mjs に記録しています。画像は配信時に取得し、リポジトリには保存しません。

配合の記録について

このノートが検索するのは利用者が登録した有効な配合だけです。配合計算用のデータや外部の配合表は取得・利用していません。

マスターの表示には図鑑番号と内部 ID を使い、花の姿などの表記を補っています。
