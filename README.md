# パル配合ノート

Palworld の配合結果（親A × 親B → 子C）を仲間内で記録・共有・検索するツールです。

**検索対象は、自分たちが登録した配合だけです。** 攻略サイトのデータや配合の計算式は使いません（例外として「理想個体」の提案だけは、ゲームの遺伝の仕組みで確率を計算します。[出典](data/SOURCES.md)）。

## このアプリの強み

- **仲間で 1 冊**: 配合の記録も所持パルも、仲間全員の画面にそろいます。ホストがセーブを読めば、参加している人の画面にも自動で届きます。
- **試した配合だけ**: 配合検索・逆引き・継承ルートに出すのは仲間が登録した配合だけで、登録者と更新の日時が付きます。攻略サイトの配合表は画面に出しません（配合牧場からの自動登録の照合にだけ使います）。
- **手入力いらず**: 配合牧場の親と、新しく産まれたタマゴをセーブから照らし合わせ、配合を自動で登録します。
- **牧場まで見る計画**: 理想個体は仲間の所持パルから、配合牧場に置く組を別々の個体で並べ、今の牧場との交換は全体の速さの目安が上がるときだけ勧めます。いちばん早く作れるケーキにも印を付けます。

類似ツールとの対応は [docs/COMPARISON.md](docs/COMPARISON.md) にまとめています。

## 構成

```
GitHub Pages（web/：画面）
   │ fetch（パスワード付き）
   ▼
Google Apps Script（gas/：API）
   ▼
Google スプレッドシート（データ）
```

- ID と共通パスワードでログインします。共通パスワードは `設定`、ID 一覧は `Users`（テストは `Users_test`）シートで管理します。更新時の初期設定は [運用手順](docs/OPERATIONS.md) を参照してください。
- 検索（配合検索・逆引き・継承ルート）はすべてブラウザの中で行います。
- PC 向けの画面です（スマホ専用の画面は作らない方針）。スマホで開くと、PC 画面を縮小して表示します。
- パル名・図鑑番号などのマスターデータは `data/` で管理し、配合データとは分けています。
- 「所持パル」では、Palworld のセーブから所持しているパル・パッシブ・場所（手持ち・パルボックス・拠点・タマゴ・グローバルパルボックス）を読み込みます。ワールドのホストが読み込んだ所持パルはスプレッドシートに共有され、参加している人も見られます。継承ルートでは、パッシブを持つ所持パルを開始候補にし、相手親の所持数を表示します（経路はこれまでどおり登録済みの配合だけを使います）。連携の設定は設定タブで行います。セーブのファイルをワールドごとに一度ドロップして登録すると、次からは自動で読み込みます（Chrome・Edge。[運用手順](docs/OPERATIONS.md)）。
- 「理想個体」では、目標のパル・欲しいパッシブ・個体値の目標から、所持パルのどの ♂×♀ を配合牧場に置くとよいかを、別々の個体の組で並べます。組は目的で分け、完全体を作れる「完全体作成組」、欲しいパッシブを集める「パッシブ厳選組」、個体値だけを狙う「個体値厳選組」の順に並べ、その中は、完全体作成組は完成までのタマゴの平均の少ない順、パッシブ厳選組は集まる欲しいパッシブの多い順、個体値厳選組は個体値がそろうまでのタマゴの平均の少ない順です（タマゴは孵化するまで候補にしません）。親の候補は、同じ種族どうしと、登録済みの配合（子が目標のもの）だけです。ケーキ 3 通りを比べ、いちばん早く作れるケーキに「最速」の印を付けます。配合牧場に置いてある組は、交換すると全体の速さの目安が上がるときだけ、どの組に交換するとよいかを出します（参加している人にも、ホストの共有から出ます）。親の候補は所持者（自分の個体・各プレイヤー）で絞り込め、目指す条件を名前を付けて登録しておくと、自分の個体で完成したときに知らせます（登録はこの端末に保存）。

## 開発

```sh
npm test              # テスト（Node 20 以上・依存なし）
npm run test:perf     # 性能テスト
npm run gas:push      # GAS へ反映（clasp）
npm run check:save    # 手元のセーブで所持パルの読み込みを確かめる
npm run build:passives  # パッシブ名のマスターを生成
npm run extract:passive-icons  # パッシブの画像をゲーム本体から取り出す
npm run extract:humans  # 人間のキャラクターの名前とアイコンをゲーム本体から取り出す
npm run extract:skills  # アクティブスキルとパートナースキルの名前と説明文をゲーム本体から取り出す
```

### 表記の決まり

画面に出す文はこの表にそろえます。左の「使わない」言い回しが `web/js` の画面の文（コメントを除く）に残っていないことを `test/static/wording.test.js` が確かめます（配った通知の履歴 `web/js/release-notes.js` は直さないので除きます）。

| 使う | 使わない・意味 |
|---|---|
| 産まれる | 生まれる |
| 親A＋親B → 子（性別は ♂・♀。文章でも「オス・メス」と書かない） | ×（親の組） |
| 所持者＝人（プレイヤー）。拠点・グローバルパルボックスは「場所」 | 拠点を所持者と呼ぶ |
| パル濃縮（★） | 凝縮（CSV の列名だけは変えない） |
| パッシブ（パッシブスキル）。アクティブスキル・パートナースキルは「スキル」 | パッシブを「スキル」 |
| 登録＝サーバ（仲間と共有する配合）／保存＝この端末（下書き・目標・既読・自分） | 端末だけのものを「登録」 |
| 画面の見出し（h1）＝タブ名（`web/js/views/tabs.js`。パル詳細は「No.番号 パル名」） | キャッチコピーの見出し |
| 設定へ移る案内は 1 文と行き先のボタン（「セーブ連携を開く」など） | 「設定タブの〜」とだけ書く |
| グローバルパルボックス・ホスト・参加者・新しいバージョン・ID（ログインの名前。「ID を変更」）・この端末だけ | グローバルボックス・参加だけ・参加している側・新しい版・（画面での）名前・この端末のみ |
