# パル配合ノート

Palworld の配合結果（親A × 親B → 子C）を仲間内で記録・共有・検索するツールです。

**検索対象は、自分たちが登録した配合だけです。** 攻略サイトのデータや配合の計算式は使いません（例外として「理想個体」の提案だけは、ゲームの遺伝の仕組みで確率を計算します。[出典](data/SOURCES.md)）。

## 構成

```
GitHub Pages（web/：画面）
   │ fetch（パスワード付き）
   ▼
Google Apps Script（gas/：API）
   ▼
Google スプレッドシート（データ）
```

- ID と共通パスワードでログインします。共通パスワードは `設定`、ID 一覧は `Users`（テストは `Users_test`）シートで管理します。更新時の初期設定は [運用手順](docs/OPERATIONS.md) を参照してください。
- 検索（配合検索・逆引き・継承ルート）はすべてブラウザの中で行います。
- PC 向けの画面です（スマホ専用の画面は作らない方針）。スマホで開くと、PC 画面を縮小して表示します。
- パル名・図鑑番号などのマスターデータは `data/` で管理し、配合データとは分けています。
- 「所持パル」では、Palworld のセーブから所持しているパル・パッシブ・場所（手持ち・パルボックス・拠点・タマゴ・グローバルパルボックス）を読み込みます。ワールドのホストが読み込んだ所持パルはスプレッドシートに共有され、参加している人も見られます。継承ルートでは、パッシブを持つ所持パルを開始候補にし、相手親の所持数を表示します（経路はこれまでどおり登録済みの配合だけを使います）。連携の設定は設定タブで行います。セーブのファイルをワールドごとに一度ドロップして登録すると、次からは自動で読み込みます（Chrome・Edge。[運用手順](docs/OPERATIONS.md)）。
- 「理想個体」では、目標のパル・欲しいパッシブ・個体値の目標から、所持パルのどの ♂×♀ を配合すると条件を満たす子が産まれやすいかを、1 個のタマゴの確率つきで提案します。親の候補は、同じ種族どうしと、登録済みの配合（子が目標のもの）だけです。「世代を重ねて最短の順」に切り替えると、産まれた子を親と入れ替えながら完成させるまでのタマゴの数が少ない順に並べます。

## 開発

```sh
npm test              # テスト（Node 20 以上・依存なし）
npm run test:perf     # 性能テスト
npm run gas:push      # GAS へ反映（clasp）
npm run check:save    # 手元のセーブで所持パルの読み込みを確かめる
npm run build:passives  # パッシブ名のマスターを生成
npm run extract:passive-icons  # パッシブの画像をゲーム本体から取り出す
npm run extract:humans  # 人間のキャラクターの名前とアイコンをゲーム本体から取り出す
```
