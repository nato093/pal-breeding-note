## 動作確認

- 画面をローカルで確認するには、`npm run dev` を実行してから `http://localhost:5173/?mock=1` を開く。架空データを入れるなら `&seed=30` を付ける。
  - モックはメモリ上だけで動くので、再読み込みで初期状態に戻る。
  - 最初に入力したパスワードをそのセッションの共通値として使う。新規登録してログインする。`seed` を指定した場合は ID `架空データ` でもログインできる。
- 本番の API を確かめるには `node scripts/smoke.mjs` を実行する。認証の確認だけで、読み取りのみ。
- 書き込みまで確かめるには `node scripts/api-check.mjs` を実行する。
  - テスト用シートに対して、登録・冪等性・重複・競合・+1・編集・削除と復元・統合・並列 5 件の書き込みを確かめる。
  - 開始時に、テスト用シートの有効レコードを片付ける。
  - 応答の環境が本番だった場合は、その時点で中断する。

## 権限の再承認

GAS に新しい権限（OAuth スコープ）が必要な変更を入れたら、スクリプトエディタで関数を 1 回実行して承認し直す。
承認するまで、匿名の利用者全員がエラーになる。

## 共通パスワードと ID

- 更新後、所有者が Apps Script エディタで `setup()` を再実行する。`設定`・`Users`・`Users_test` シートと保護されたヘッダーを追加する。既存の配合データと設定値は変えない。
- 本番の共通パスワードは `設定` シートの `項目` が `共通パスワード` の行の `値` に保存する。初回は旧 Script Property `PASSCODE` を移行し、旧プロパティを削除する。旧値がなければ自動生成する。値はログに出さない。
- 変更するときは、そのセルを直接書き換えて利用者に新しい共通パスワードを伝える。値の列は書式なしテキスト（`@`）を保つ。数字だけの値も文字として入力する。
- 照合は前後の空白を除いた完全一致で、大文字小文字・記号・日本語を区別する。設定が空、シートや行がない、テスト値が空、両者が同じ場合は全リクエストを拒否する。
- `Users` は本番の ID 一覧、`Users_test` はテストの ID 一覧。列は `userId` / `createdAt`。利用者は画面の新規登録から ID を追加する。ID は制御文字と前後の空白を除いた1〜20文字で、全角英数や大文字小文字が違っても同じ ID とみなす。
- ID の確認・削除は該当する Users シートで行う。削除した ID の端末は次のデータ取得時にログアウトする。配合レコードの登録者名や既存レコードは変わらない。
- パスワード変更後は次の API 通信で再ログインが必要になる。端末には成功時の ID とパスワードを保存する。設定画面のログアウトでパスワードとキャッシュを消去し、次回入力用の ID は残す。
- テスト用は従来どおり Script Properties の `TEST_PASSCODE` を使う（AI・開発者専用）。`.env.local` の `PAL_TEST_PASSCODE` に保存する（コミットしない）。必要な場合のみ `TEST_PASSCODE` を消して `setup()` を再実行すると作り直される。

## 所持パル（セーブ連携とスプレッドシートでの共有）

画面の「所持パル」は、Palworld のセーブから所持パル・パッシブ・場所を読み込む。ワールドのホストの画面が、読み込んだ内容をスプレッドシートに共有し、参加している人はそれを見る。セーブの構成は [SAVE_FORMAT.md](SAVE_FORMAT.md) を参照。

### 初回の導入（GAS）

- `npm run gas:push` → `npx clasp update-deployment <deployment ID>` で GAS を更新する。
- 所有者が Apps Script エディタで `setup()` を再実行し、`OwnedPals`・`OwnedWorlds`（テスト用は `OwnedPals_test`・`OwnedWorlds_test`）のシートを作る。既存のシートとデータは変えない。実行するまでは共有がエラーになる（この PC で読み込んだ所持パルは見られる）。
- 新しい権限は要らない（同じスプレッドシートを読み書きするだけ）。
- `OwnedWorlds` はワールドごとに 1 行（ワールド名・ホスト名・セーブの更新時刻・共有した時刻と ID・体数・プレイヤーと拠点の一覧）。`OwnedPals` はパルごとに 1 行（`worldId` と、`web/js/core/owned-shared.js` の `OWNED_FIELDS` の列）。シートを直接編集しても、次に共有されたときに上書きされる。

### 設定（設定タブの「所持パル（セーブ連携）」）

- 連携の方法は「セーブのファイルを登録（自動）」と「フォルダを選ぶ（手動）」の 2 通り。どちらも設定していないときは、所持パルのタブに案内だけ出す。
- ホストか参加している側かは、`Level.sav` と `LocalData.sav` の更新日時で決める（`web/js/save/source.js` の `judgeRole`）。`LocalData.sav` が `Level.sav` より 10 秒以上新しい、または `LocalData.sav` しかなければ参加している側（フォルダ名はホストのワールド ID と同じ）、それ以外で `Level.sav` があればホスト。
  - ホストで保存すると 2 つはほぼ同時に書かれ、参加すると `LocalData.sav` だけが書かれる。前にホストしたワールドに参加した場合、古い `Level.sav` が残るが、`LocalData.sav` の方が新しいので参加と判定する。
  - ホスト: 読み込んだ所持パルをスプレッドシートに共有する。60 秒以上空け、その間の更新はまとめて最新を送る。
  - 参加している側: 自分のセーブは読まず、ホストが共有した同じワールドの所持パルを出す。
  - 連携していない人は、「表示するワールド」で共有されているワールドを選ぶ（既定は、いちばん新しいセーブが共有されたワールド）。
- 共有されたデータは、所持パル・継承ルートを開いたときとタブに戻ったときに読み直す（30 秒以上空ける）。
- 共有はワールドごとに丸ごと置き換える。セーブから消えたパルはシートからも消える。
- 競合したとき（同じワールドを別の PC からも共有した、など）は、セーブの更新時刻が新しい方を残す。古いセーブは GAS が受け付けず、画面は新しい方を出す。この PC で読み込んだものと共有されたものがあるときも、新しい方を出す。
- 所持パルのタブには、表示しているワールド・体数と、更新時刻（セーブの更新・共有した時刻と ID・この PC で読み込んだ時刻）を出す。
- 「連携の設定を解除」で、連携の設定と、このブラウザに読み込んだセーブを消す。共有された所持パルは引き続き見られる。
- 「共有した所持パルを削除」（ホストで、共有済みのときだけ出る）で、表示しているワールドの所持パルをスプレッドシートから消す。次にセーブを読み込んだときに、また共有される。

### セーブのファイルの登録（自動の読み込み）

- ブラウザ（Chrome・Edge）は `AppData` 配下のフォルダを開けないが、エクスプローラーからドロップした**ファイル**のハンドルは受け取れ、IndexedDB に保存して後から読み直せる（`web/js/save/handles.js`）。以前のセーブ連携ツール（ローカルの中継）は廃止した。
- 登録はワールドごとに 1 回（設定タブの「セーブのファイルを登録して自動で読み込む」）。
  1. エクスプローラーでワールドのフォルダ（`%LOCALAPPDATA%\Pal\Saved\SaveGames\<Steam ID>\<ワールド ID>`）を開き、アドレス欄のパスを貼る。セーブのファイルにはワールド ID が入っていないため、パスから ID を取る。
  2. 画面に出る場所のファイルをドロップする（何回かに分けて足せる）。ホストのワールドは `Level.sav`・`LevelMeta.sav`・`LocalData.sav`（必須）と `Players` の中のファイル全部、任意で 1 つ上の `GlobalPalStorage.sav`。参加しただけのワールドは `LocalData.sav` だけ。
  3. 「確認する」で読み込んでワールド名・ホスト名・体数を出す（まだ保存・共有しない）。「このワールドで登録」で保存し、読み込みと共有を始める。貼ったパスとドロップしたファイルが同じワールドかは機械では確かめられないので、ワールド名で確かめる。
- 登録した後は、所持パル・継承ルートを開いたときとタブに戻ったときに、登録したワールドの中から最後に遊んだワールドを選び、セーブが更新されていれば読み直す（20 秒以上空ける）。別のワールドに固定するときは設定タブの選択欄で選ぶ。
- 読む許可: 初めて読むとき（またはブラウザを開き直したとき）に Chrome が許可を求める。「毎回のアクセスを許可」を選ぶと、次からは確認なしで読む。許可が要るときは所持パル・設定タブに「読み込みを許可」ボタンが出る（許可のないワールドがあるときは、別のワールドを黙って選ばない）。拒否した場合は Chrome のサイトの設定で許可を戻すか、登録し直す。
- 読み込みで飛ばすのは、必須（`Level.sav`・`LevelMeta.sav`・`LocalData.sav`）以外の消えたファイルだけ（所持パルのタブに知らせる）。読めないエラー（許可・ゲームの保存中など）は失敗にし、共有もしない。必須のファイルが読めないワールドは、ホストか参加かを判定せず、共有を止める。選んでいなければ、読めるワールドのうち最後に遊んだものを読み、読めないワールドがあれば知らせる。
- 共有は、このページでホストのワールドのセーブを正常に読めたときだけ行う（開き直した直後は、保存済みのデータがあっても一度読み直す）。読み込みの途中で登録の削除・解除を押した場合、その読み込みの結果では共有しない。
- 1 回のドロップに同じ名前のファイル（同じ場所に入るもの）が 2 つ以上あると、どれが正しいか分からないので、そのファイルはどれも受け取らない。
- 同じワールドかは、ワールド ID（フォルダ名）だけで見分ける。参加すると、自分の PC にホストのワールド ID と同じ名前のフォルダができ、`LocalData.sav` だけが書かれる。ワールドデータを仲間に渡すときにフォルダごとコピーすれば ID は変わらないので、誰がホストしても同じワールドとして扱える（前にホストしたワールドに参加すると、更新日時で参加と判定する）。フォルダ名を変えると別のワールドになる。
- 一度もホストしていないワールドに参加するときは、そのワールドの `LocalData.sav` を 1 回登録しておくと、遊んだワールドとして自動で選ばれる。
- 登録した後に仲間が増えると、その人の `Players\<ID>.sav` は登録されていない。所持パルのタブに案内が出るので、同じパスを貼ってドロップして足す。
- 登録は設定タブの一覧から 1 件ずつ削除できる。「連携の設定を解除」で全部消す。IndexedDB に保存できないブラウザ（シークレットウィンドウなど）では、ページを開いている間だけ使う。
- Firefox など、ドロップからハンドルを取り出せないブラウザでは登録欄を出さず、手動の読み込みを案内する。
- 登録しない場合は、設定タブの「フォルダを選んで読み込む」でワールドのフォルダ（または Steam ID のフォルダ）を選ぶか、エクスプローラーからフォルダをドロップする。ブラウザの制限で、この方法は毎回の手動操作になる。
- ゲームの保存の途中で読むと失敗することがある。少し待ってから「今すぐ読み込む」を押す。
- 手元のセーブで読み込みを確かめるには `npm run check:save -- "<ワールドのフォルダ>"`（省略すると最後に遊んだホストのワールド）。

### 表示と画像

- 「タマゴも表示」（既定はオン）で、牧場などにあるタマゴも出す。「グローバルボックスを表示」（既定はオフ）で、グローバルパルボックスのパルも出す。継承ルートは、この切り替えに関係なく所持パル全体を使う（開始候補にはタマゴとグローバルボックスも含める。相手親の所持数はグローバルボックスを含め、タマゴは数えない）。
- 人間のキャラクター（密猟団・賞金首など、パルのマスターにないもの）は、ゲーム本体から取り出した日本語名とアイコン（`web/data/humans.js`・`web/img/humans/`）で出す。ゲームの更新で作り直すときは `npm run extract:humans -- "<Palworld のインストール先>"`。
- 一覧（所持パル・みんなの配合ノート）と継承ルートの候補は、件数が多くても最初から全部出す。
- パルの画像は図鑑と同じ（`web/img/pals/`）。ローカルで画像が出ないときは `npm run fetch:icons` を実行する（配信時は GitHub Actions が取得する）。
- 絞り込みは、所持者・場所・パル・キーワード・パル濃縮（★の数、以上）・個体値（HP・攻撃・防御、それぞれ以上）・パッシブ（すべて持つ個体）。
- パッシブの見た目はゲームのパル詳細画面に合わせる。ランクの矢印と背景の三角模様はゲーム本体から取り出した画像（`web/img/passive/`）、左の帯・枠・板の色はゲーム画面から測った値を CSS で描く（ランク 1・2 は白、3 は金、4 は水色、マイナスは赤。ランク 5 は見本がないため推定）。ゲームの更新で画像を作り直すときは `npm run extract:passive-icons -- "<Palworld のインストール先>"`。
- 一覧は設定タブの「所持パルを CSV で保存」で Excel 用の CSV（UTF-8・BOM 付き）に出せる。列は `web/js/core/owned.js` の `OWNED_COLUMNS`。
- パッシブ名のマスターを更新するには `npm run build:passives`（取得元のコミットは `scripts/sources.mjs` の PalCalc と同じ）。
